STEP 1 · 解鎖資料庫

資料庫裡是加密過的文獻全文，請輸入研究者給你的密碼。

STEP 2 · 連接你的 Gemini

分析照片使用你自己的 Gemini API Key，費用算在你的帳號。Key 只存在這個瀏覽器，不會傳到其他地方。還沒有 Key？看下方「怎麼取得 Gemini API Key」。

怎麼取得 Gemini API Key

有 Google AI Pro 訂閱（建議）

Pro 訂閱不會直接增加 API 次數，但每個月附 Google Cloud 額度，可以拿來付 API 費用。比對一件文物大約不到 1 美分。

  1. 用訂閱 Pro 的 Google 帳號打開 Google Developer Program 的 My Benefits，領取每月的 Google Cloud 額度，依指示建立或選擇一個 Cloud 帳單帳戶（可能需要登記信用卡，但會先扣額度）。
  2. 打開 Google AI Studio 的 API Keys 頁面，按「Create API key」，選擇連到上一步帳單帳戶的專案。
  3. 複製 Key（AIza 開頭），貼到上面的 STEP 2，按「連接」。

沒有訂閱

  1. 直接到 Google AI Studio 建立 Key，可以用免費額度。
  2. 免費額度每天次數很少（每次比對用 2 次），而且免費版的資料 Google 可能拿去改進模型。

每次比對會把照片和查到的書頁段落送到 Google Gemini。額度用完會顯示「已達使用上限」，隔天（美國太平洋時間午夜）會重置。
